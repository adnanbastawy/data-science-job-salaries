# Data Science Job Salaries Analysis

## Overview

This project analyzes data science job salaries to understand salary patterns across different job roles, experience levels, employment types, company sizes, and locations.

The project includes data cleaning, exploratory data analysis (EDA), and an interactive Power BI dashboard to present the main findings.

## Objectives

* Analyze salary differences across job roles and experience levels.
* Explore salary patterns by company size and employment type.
* Compare salaries across different locations.
* Identify the most common job roles and employment categories.
* Build an interactive dashboard to communicate the findings.

## Project Workflow

The project follows these main steps:

1. Data Cleaning
2. Data Exploration
3. Data Analysis
4. Data Visualization
5. Business Insights
6. Power BI Dashboard

## Dataset

The dataset contains information about data science-related jobs, including:

* Job title
* Experience level
* Employment type
* Company size
* Employee residence
* Remote work ratio
* Company location
* Salary information

The dataset was cleaned and prepared before performing the analysis.

## Data Analysis

The analysis explores relationships between:

* Experience level and salary
* Job title and salary
* Company size and salary
* Employment type and salary
* Location and salary
* Remote work ratio and salary

## Power BI Dashboard

An interactive Power BI dashboard was created to visualize the main findings from the analysis.

The dashboard allows users to explore salary information using different categories and filters.
